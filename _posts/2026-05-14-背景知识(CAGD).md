## 1. 多项式样条空间

首先我们给出多项式样条空间的定义：

**定义 1（多项式样条空间）**

设分割

<script type="math/tex; mode=display">\Delta := \{x_i\}_{i=1}^k, \quad a = x_0 < x_1 < \cdots < x_k < x_{k+1} = B</script>

将有限闭区间 <script type="math/tex">[a,b]</script> 分为 <script type="math/tex">k+1</script> 个小区间：
- <script type="math/tex">I_i := [x_i, x_{i+1}) \;(i=0,1,\cdots,k-1)</script>
- <script type="math/tex">I_{k+1} := [x_k, x_{k+1}]</script>

再设 <script type="math/tex">\mathfrak{M} := (m_1, m_2, \cdots, m_k)</script> 为一个向量，其中正整数 <script type="math/tex">m_i \;(i=1,2,\cdots,k)</script> 满足 <script type="math/tex">1 \leq m_i \leq m</script>。

称空间

<script type="math/tex; mode=display">\mathcal{S}(\mathcal{P}_m, \mathfrak{M}, \Delta) := \left\{s : \begin{array}{l} s(x)=s_i(x)\in\mathcal{P}_m,\; x\in I_i\;(i=0,1,\cdots,k), \\ D^j s_{i-1}(x_i)=D^j s_i(x_i)\;(i=1,2,\cdots,k;\; j=0,1,\cdots,m-1-m_i) \end{array}\right\}</script>

为 <script type="math/tex">m</script> 阶的、**重度向量**为 <script type="math/tex">\mathfrak{M}</script> 的、以 <script type="math/tex">x_1, x_2, \cdots, x_k</script> 为节点的**多项式样条空间**。

**注：**

1. 其中 <script type="math/tex">\mathcal{P}_m := \left\{ \sum_{i=0}^{m-1} a_i t^i ,a_i \in \mathbb{R}\right\}</script> 为 <script type="math/tex">m</script> 阶多项式的全体。
2. 从定义可以看出 <script type="math/tex">\mathcal{S}</script> 中的元素 <script type="math/tex">s(x)</script> 是具有一定光滑性的分片 <script type="math/tex">m</script> 阶多项式，每个节点处的光滑性由重度向量 <script type="math/tex">\mathfrak{M}</script> 决定。
   - <script type="math/tex">m_i=m</script> 说明 <script type="math/tex">s(x)</script> 在 <script type="math/tex">x_i</script> 处可能不连续
   - <script type="math/tex">m_i \lt m</script> 说明 <script type="math/tex">s(x)</script> 在 <script type="math/tex">x_i</script> 处 <script type="math/tex">C^{m-1-m_i}</script> 连续
3. 若 <script type="math/tex">\mathfrak{M}=(m,m,\cdots,m)</script>，则 <script type="math/tex">\mathcal{S}(\mathcal{P}_m,\mathfrak{M},\Delta)=\mathcal{PP}_m(\Delta)</script>，即 <script type="math/tex">m</script> 阶**分片多项式空间**
4. 若 <script type="math/tex">\mathfrak{M}=(1,1,\cdots,1)</script>，则 <script type="math/tex">\mathcal{S}=\mathcal{S}_m(\Delta)</script>，即 <script type="math/tex">m</script> 阶**单节点的多项式样条空间**，<script type="math/tex">\mathcal{S}_m(\Delta)\subset C^{m-2}[a,b]</script>

对于空间 <script type="math/tex">\mathcal{S}</script>，我们有如下定理：

**定理 1：**

1. 对任意的 <script type="math/tex">s(x)\in \mathcal{S}(\mathcal{P}_m,\mathfrak{M},\Delta)</script>，必定存在 <script type="math/tex">p(x)\in \mathcal{P}_m</script> 和实数 <script type="math/tex">\{\alpha_{ij}\}_{i=1,\,j=1}^{k\;\;\;m_i}</script> 使得

<script type="math/tex; mode=display">s(x)=p(x)+\sum_{i=1}^{k} \sum_{j=1}^{m_i} \alpha_{ij}(x-x_i)_+^{m-j}</script>

其中

<script type="math/tex; mode=display">x_+^0 := \begin{cases} 1, & x \ge 0, \\ 0, & x < 0, \end{cases} \qquad x_j^+ = x^j \cdot x_+^0</script>

2. 空间 <script type="math/tex">\mathcal{S}</script> 的维数为 <script type="math/tex">dim(\mathcal{S})=m+\mathbf{K}</script>，其中 <script type="math/tex">\mathbf{K}=\sum\limits_{i=1}^{k} m_i</script>

**推论：**

<script type="math/tex; mode=display">dim \mathcal{PP}_m(\Delta)=(k+1)m, \quad dim \mathcal{S}_m(\Delta)=m+k</script>

从定理可以看出，<script type="math/tex">(x-x_i)_+^{m-j}(i=0,\cdots,k;j=1,\cdots,m_i)</script> 是空间 <script type="math/tex">\mathcal{S}</script> 的一组基。但是从计算的角度来看，这组基并不好，因为它没有局部性质：当 <script type="math/tex">x</script> 接近 <script type="math/tex">b</script> 时，为了计算 <script type="math/tex">s(x)</script>，需要计算所有基函数的值。我们需要更加局部化、对称化的基。

## 2. 差商

下面我们开始介绍 B 样条，在此之前先介绍差商：

**定义 2（差商）：**

给定节点

<script type="math/tex; mode=display">t_1 \le t_2 \le \cdots \le t_{r+1} = \underbrace{\tau_1,\cdots,\tau_1}_{l_1} < \underbrace{\tau_2,\cdots,\tau_2}_{l_2} < \ldots < \underbrace{\tau_d,\cdots,\tau_d}_{l_d},\;\sum_{i=1}^d l_i = r+1</script>

和函数 <script type="math/tex">f</script>，<script type="math/tex">f</script> 在点 <script type="math/tex">t_1, t_2, \cdots, t_{r+1}</script> 的 <script type="math/tex">r</script> 次**差商**为：

<script type="math/tex; mode=display">[t_1,t_2]f:= \begin{cases} \frac{f(t_2)-f(t_1)}{t_2-t_1} & t_1<t_2, \\ f^{'}(t_1) & t_1=t_2, \end{cases}</script>

<script type="math/tex; mode=display">[t_1,t_2,\cdots,t_{r+1}]f:= \begin{cases} \frac{[t_2,t_3,\cdots,t_{r+1}]f-[t_1,t_2,\cdots,t_r]f}{t_{r+1}-t_1} & t_1<t_{r+1}, \\ \frac{1}{r!}f^{(r)}(t_1) & t_1=t_{r+1}, \end{cases}</script>

## 3. B 样条

有了差商的定义，我们可以开始介绍 B 样条：

**定义 3（B 样条）：**

设 <script type="math/tex">\{y_i\}_{i=-\infty}^{+\infty}</script> 为一不减的实数列，对给定的整数 <script type="math/tex">i</script> 和 <script type="math/tex">m\gt0</script> 及所有实数 <script type="math/tex">x</script>，称

<script type="math/tex; mode=display">Q_i^m(x):= \begin{cases} (-1)^m[y_i,y_{i+1},\cdots,y_{i+m}](x-\cdot)_+^{m-1} & y_i<y_{i+m}, \\ 0 & y_i=y_{i+m} \end{cases}</script>

为 <script type="math/tex">m</script> 阶的、节点为 <script type="math/tex">y_i,y_{i+1},\cdots,y_{i+m}</script> 的**B 样条**。

若

<script type="math/tex; mode=display">y_i \le y_{i+1} \le \cdots \le y_{i+m} = \underbrace{\tau_1,\cdots,\tau_1}_{m_1} < \underbrace{\tau_2,\cdots,\tau_2}_{m_2} < \ldots < \underbrace{\tau_d,\cdots,\tau_d}_{m_d},</script>

则 <script type="math/tex">Q_i^m(x)</script> 显然是 <script type="math/tex">m</script> 阶的、节点为 <script type="math/tex">\tau_1,\tau_2,\cdots,\tau_d</script> 的、重度向量为 <script type="math/tex">(m_1,m_2,\cdots,m_d)</script> 的样条函数。

由定义，可以很容易地计算出一些特殊的 B 样条：

1. **<script type="math/tex">m=1</script> 时：**

<script type="math/tex; mode=display">Q_i^1(x)= \begin{cases} \frac{1}{y_{i+1}-y_i} & y_i \le x<y_{i+1}, \\ 0 & \text{else} \end{cases}</script>

2. **<script type="math/tex">y_i\lt y_{i+1}=\cdots=y_{i+m}</script> 时：**

<script type="math/tex; mode=display">Q_i^m(x)= \begin{cases} \frac{(x-y_i)^{m-1}}{(y_{i+m}-y_i)^m} & y_i \le x<y_{i+m}, \\ 0 & \text{else} \end{cases}</script>

3. **<script type="math/tex">y_i=y_{i+1}=\cdots=y_{i+m-1}\lt y_{i+m}</script> 时：**

<script type="math/tex; mode=display">Q_i^m(x)= \begin{cases} \frac{(y_{i+m}-x)^{m-1}}{(y_{i+m}-y_i)^m} & y_i \le x<y_{i+m}, \\ 0 & \text{else} \end{cases}</script>

考虑 <script type="math/tex">m=1</script> 时，<script type="math/tex">Q_i^1(x)=\frac{1}{y_{i+1}-y_i}\;(y_i \le x\lt y_{i+1})</script>，对不同的 <script type="math/tex">y_i</script> 和 <script type="math/tex">y_{i+1}</script>，<script type="math/tex">Q_i^1(x)</script> 可能会非常大或非常小，这会给数值计算带来很大的误差。因此我们引入**规范 B 样条**：

**定义 4（规范 B 样条）：**

称

<script type="math/tex; mode=display">N_i^m(x):= (y_{i+m}-y_i)Q_i^m(x)</script>

为 <script type="math/tex">m</script> 阶的、节点为 <script type="math/tex">y_i,y_{i+1},\cdots,y_{i+m}</script> 的**规范 B 样条**。

显然 <script type="math/tex">m=1</script> 时，

<script type="math/tex; mode=display">N_i^1(x)= \begin{cases} 1 & y_i \le x<y_{i+1}, \\ 0 & \text{else} \end{cases}</script>

---

### 3.1 B 样条的性质

**定理 2（B 样条的性质）：**

1. **B 样条函数满足递推关系**：设 <script type="math/tex">m\ge2, y_i\lt y_{i+m}</script>，则对所有的 <script type="math/tex">x\in\mathbb{R}</script>，有

    <script type="math/tex; mode=display">Q_i^m(x)=\frac{(x-y_i)Q_i^{m-1}(x)+(y_{i+m}-x)Q_{i+1}^{m-1}(x)}{y_{i+m}-y_i}</script>

2. **B 样条的局部支撑性质**：
   - 设 <script type="math/tex">y_l\lt y_{l+1}</script>，则在区间 <script type="math/tex">I_l:=[y_l,y_{l+1}]</script> 上 <script type="math/tex">\mathcal{P}_m=span\{Q_i^m(x)\}_{i=l+1-m}^l</script>
   - 若 <script type="math/tex">l\lt r, y_{r-1}\lt y_r</script>，则 <script type="math/tex">\{Q_i^m(x)\}_{i=l+1-m}^{r-1}</script> 在 <script type="math/tex">[y_l,y_r)</script> 上线性无关

3. **规范 B 样条形成单位分解**：即对任意 <script type="math/tex">x\in[y_j,y_{j+1})</script>，有 <script type="math/tex">\sum_{i=j+1-m}^{j}N_i^m(x)=1</script>

4. 设 <script type="math/tex">y_i\lt y_{i+m}, m\gt1, D_+</script> 为右导数算子，则

    <script type="math/tex; mode=display">D_+Q_i^m(x)=(m-1)\frac{Q_i^{m-1}(x)-Q_{i+1}^{m-1}(x)}{y_{i+m}-y_i}</script>

5. 设 <script type="math/tex">y_i\lt y_{i+m}</script>，则

    <script type="math/tex; mode=display">Q_i^m(x)>0\;,\;y_i<x<y_{i+m}</script>

    <script type="math/tex; mode=display">Q_i^m(x)=0\;,\;x<y_i\;\text{或}\;x>y_{i+m}</script>


---

### 3.2 扩充分割

有了 B 样条，现在我们可以建立空间 <script type="math/tex">\mathcal{S}(\mathcal{P}_m,\mathfrak{M},\Delta)</script> 的一个有局部支集的基底。

我们知道 <script type="math/tex">dim(\mathcal{S})=m+\mathbf{K}</script>，其中 <script type="math/tex">\mathbf{K}</script> 为分割 <script type="math/tex">\Delta</script> 的节点数。然而在 <script type="math/tex">\mathbf{K}</script> 个节点上只能定义 <script type="math/tex">\mathbf{K}-m</script> 个 B 样条，因此我们还需要加入 <script type="math/tex">2m</script> 个点。于是，我们引入**扩充分割**：

**定义 5（扩充分割）：**

对给定的 <script type="math/tex">a\lt x_1\lt\cdots\lt x_k\lt b</script> 和 <script type="math/tex">1\le m_i\le m(i=1,\cdots,k)</script>，若 <script type="math/tex">y_1\le y_2\le\cdots\le y_{2m+\mathbf{K}}</script> 满足

<script type="math/tex; mode=display">y_1\le y_2\le\cdots\le y_m\le a,\;\;b\le y_{m+\mathbf{K}+1}\le\cdots\le y_{2m+\mathbf{K}},</script>

<script type="math/tex; mode=display">y_{m+1}\le y_{m+2}\le\cdots\le y_{m+\mathbf{K}}=\underbrace{x_1,\cdots,x_1}_{m_1}<\cdots<\underbrace{x_k,\cdots,x_k}_{m_k},</script>

则称 <script type="math/tex">\{y_i\}_{i=1}^{2m+\mathbf{K}}</script> 为空间 <script type="math/tex">\mathcal{S}(\mathcal{P}_m,\mathfrak{M},\Delta)</script> 的扩充分割。

一种特殊取法为

<script type="math/tex; mode=display">y_1=y_2=\cdots=y_m=a,\quad y_{m+\mathbf{K}+1}=\cdots=y_{2m+\mathbf{K}}=b</script>

这样我们在 <script type="math/tex">\{y_i\}_{i=1}^{2m+\mathbf{K}}</script> 上定义了 <script type="math/tex">m+\mathbf{K}</script> 个 B 样条 <script type="math/tex">\{B_i(x)\}_{i=1}^{m+\mathbf{K}}</script>，即 <script type="math/tex">N_i^m(x)</script>。

## 4. 样条函数的计算

现在我们已经有了多项式样条空间的一组有局部支集的基，可以开始考虑样条函数及其导数值的计算。

**定理 3（de Boor 算法）：**

设 <script type="math/tex">s(x)=\sum_{i}c_iN_i^m(x) \qquad (y_l\leq x\lt y_{l+1})</script>

则

<script type="math/tex; mode=display">s(x) =\sum_{i=l+1-m}^{l}c_i^{[0]}N_i^m(x)=\cdots=c_i^{[m-1]}</script>

其中

<script type="math/tex; mode=display">c_i^{[0]}=c_i</script>

<script type="math/tex; mode=display">c_i^{[j+1]}=\alpha_jc_i^{[j]}+(1-\alpha_j)c_{i-1}^{[j]} \qquad (j=0,1,\cdots,m-2)</script>

<script type="math/tex; mode=display">\alpha_j=\frac{x-y_i}{y_{i+m-1-j}-y_i}</script>

类似的，可以计算 <script type="math/tex">s(x)</script> 的导数值

<script type="math/tex; mode=display">D_+^ds(x)=\sum_{i=l+d+1-m}^{l}c_i^{[d]}N_i^{m-d}(x)</script>

其中

<script type="math/tex; mode=display">c_i^{[0]}=c_i</script>

<script type="math/tex; mode=display">c_i^{[d]}=\frac{(m-d)(c_i^{[d-1]}-c_{i-1}^{[d-1]})}{y_{i+m-d}-y_i} \qquad (d=1,2,\cdots)</script>

## 5. 多项式的开花（极形式）

接下来，我们引入多项式的开花（即极形式）：

**定义 6（多项式的开花/极形式）：**

设 <script type="math/tex">b(u)</script> 是一个 <script type="math/tex">n</script> 次多项式，将满足对角关系的、对称的、<script type="math/tex">n</script> 仿射的多项式 <script type="math/tex">b(u_1,u_2,\cdots,u_n)</script> 称为多项式 <script type="math/tex">b(u)</script> 的**开花**，或**极形式**。

- **对角关系**：<script type="math/tex">b(u)=b(u,\cdots,u)</script>
- **对称**：<script type="math/tex">b(u_1,u_2,\cdots,u_n)=b(u_{\sigma(1)},u_{\sigma(2)},\cdots,u_{\sigma(n)})</script>
- **<script type="math/tex">n</script> 仿射**：对每一个变量 <script type="math/tex">u_i</script> 都是仿射的

**定理 4：**

对于任意 <script type="math/tex">n</script> 次多项式 <script type="math/tex">b(u)</script>，存在唯一的开花，且

<script type="math/tex; mode=display">b_i=b(\underbrace{0,\cdots,0}_{n-i},\underbrace{1,\cdots,1}_i) \qquad (i=0,1,\cdots,n)</script>

是 <script type="math/tex">b(u)</script> 在 <script type="math/tex">[0,1]</script> 上的 **Bézier 系数**，即

<script type="math/tex; mode=display">b(u)=\sum_{i=0}^{n}b_iB_i^n(u)</script>

其中 <script type="math/tex">B_i^n(u):= \binom{n}{i}u^i(1-u)^{n-i}</script> 为 Bernstein 多项式。

---

## 6. 广义 de Boor 算法

**定理 5（广义 de Boor 算法）：**

假设已知 <script type="math/tex">n+1</script> 个值 <script type="math/tex">b(t_{i+1},t_{i+2},\cdots,t_{i+n})\;\;(i=0,1,\cdots,n)</script>，我们可以通过如下算法计算 <script type="math/tex">b(u_1,u_2,\cdots,u_n)</script>：

<script type="math/tex; mode=display">b_i^0=b(t_{i+1},t_{i+2},\cdots,t_{i+n})</script>

<script type="math/tex; mode=display">b_i^r(u_1,u_2,\cdots,u_r)=\frac{u_r-t_i}{t_{i+n+1-r}-t_i}b_i^{r-1}(u_1,u_2,\cdots,u_{r-1})+\frac{t_{i+n+1-r}-u_r}{t_{i+n+1-r}-t_i}b_{i-1}^{r-1}(u_1,u_2,\cdots,u_{r-1})</script>

从而 <script type="math/tex">b_n^n(u_1,u_2,\cdots,u_n)=b(u_1,u_2,\cdots,u_n)</script>

## 总结

本文介绍了 CAGD 中的基础理论知识：

1. **多项式样条空间**：分片多项式构成的函数空间，具有一定的光滑性
2. **差商**：B 样条定义的基础
3. **B 样条**：具有局部支集的基函数，是 CAGD 的核心工具
4. **de Boor 算法**：高效计算样条函数值的算法
5. **极形式（开花）**：多项式的几何表示

这些知识为后续学习 NURBS、非均匀 B 样条等高级内容奠定了基础。

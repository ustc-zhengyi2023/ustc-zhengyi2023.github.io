## 1. 多项式样条空间

首先我们给出多项式样条空间的定义：

**定义 1（多项式样条空间）**

设分割

<div class="math-display">\[
\Delta \triangleq \{x_i\}_{i=1}^k, \quad a = x_0 < x_1 < \cdots < x_k < x_{k+1} = B
\]</div>

将有限闭区间 <span class="math-inline">\([a,b]\)</span> 分为 <span class="math-inline">\(k+1\)</span> 个小区间：
- <span class="math-inline">\(I_i \triangleq [x_i, x_{i+1}) \;(i=0,1,\cdots,k-1)\)</span>
- <span class="math-inline">\(I_{k+1} \triangleq [x_k, x_{k+1}]\)</span>

再设 <span class="math-inline">\(\mathfrak{M} \triangleq (m_1, m_2, \cdots, m_k)\)</span> 为一个向量，其中正整数 <span class="math-inline">\(m_i \;(i=1,2,\cdots,k)\)</span> 满足 <span class="math-inline">\(1 \leq m_i \leq m\)</span>。

称空间

<div class="math-display">\[
\mathcal{S}(\mathcal{P}_m, \mathfrak{M}, \Delta) \triangleq \left\{s : \begin{array}{l} s(x)=s_i(x)\in\mathcal{P}_m,\; x\in I_i\;(i=0,1,\cdots,k), \\ D^j s_{i-1}(x_i)=D^j s_i(x_i)\;(i=1,2,\cdots,k;\; j=0,1,\cdots,m-1-m_i) \end{array}\right\}
\]</div>

为 <span class="math-inline">\(m\)</span> 阶的、**重度向量**为 <span class="math-inline">\(\mathfrak{M}\)</span> 的、以 <span class="math-inline">\(x_1, x_2, \cdots, x_k\)</span> 为节点的**多项式样条空间**。

**注：**

1. 其中 <span class="math-inline">\(\mathcal{P}_m \triangleq \left\{ \sum_{i=0}^{m-1} a_i t^i ,a_i \in \mathbb{R}\right\}\)</span> 为 <span class="math-inline">\(m\)</span> 阶多项式的全体。
2. 从定义可以看出 <span class="math-inline">\(\mathcal{S}\)</span> 中的元素 <span class="math-inline">\(s(x)\)</span> 是具有一定光滑性的分片 <span class="math-inline">\(m\)</span> 阶多项式，每个节点处的光滑性由重度向量 <span class="math-inline">\(\mathfrak{M}\)</span> 决定。
   - <span class="math-inline">\(m_i=m\)</span> 说明 <span class="math-inline">\(s(x)\)</span> 在 <span class="math-inline">\(x_i\)</span> 处可能不连续
   - <span class="math-inline">\(m_i < m\)</span> 说明 <span class="math-inline">\(s(x)\)</span> 在 <span class="math-inline">\(x_i\)</span> 处 <span class="math-inline">\(C^{m-1-m_i}\)</span> 连续
3. 若 <span class="math-inline">\(\mathfrak{M}=(m,m,\cdots,m)\)</span>，则 <span class="math-inline">\(\mathcal{S}(\mathcal{P}_m,\mathfrak{M},\Delta)=\mathcal{PP}_m(\Delta)\)</span>，即 <span class="math-inline">\(m\)</span> 阶**分片多项式空间**
4. 若 <span class="math-inline">\(\mathfrak{M}=(1,1,\cdots,1)\)</span>，则 <span class="math-inline">\(\mathcal{S}=\mathcal{S}_m(\Delta)\)</span>，即 <span class="math-inline">\(m\)</span> 阶**单节点的多项式样条空间**，<span class="math-inline">\(\mathcal{S}_m(\Delta)\subset C^{m-2}[a,b]\)</span>

对于空间 <span class="math-inline">\(\mathcal{S}\)</span>，我们有如下定理：

**定理 1：**

1. 对任意的 <span class="math-inline">\(s(x)\in \mathcal{S}(\mathcal{P}_m,\mathfrak{M},\Delta)\)</span>，必定存在 <span class="math-inline">\(p(x)\in \mathcal{P}_m\)</span> 和实数 <span class="math-inline">\(\{\alpha_{ij}\}_{i=1,\,j=1}^{k\;\;\;m_i}\)</span> 使得

<div class="math-display">\[
s(x)=p(x)+\sum_{i=1}^{k} \sum_{j=1}^{m_i} \alpha_{ij}(x-x_i)_+^{m-j}
\]</div>

其中

<div class="math-display">\[
x_+^0 \triangleq \begin{cases} 1, & x \ge 0, \\ 0, & x < 0, \end{cases} \qquad x_j^+ = x^j \cdot x_+^0
\]</div>

2. 空间 <span class="math-inline">\(\mathcal{S}\)</span> 的维数为 <span class="math-inline">\(dim(\mathcal{S})=m+\mathbf{K}\)</span>，其中 <span class="math-inline">\(\mathbf{K}=\sum\limits_{i=1}^{k} m_i\)</span>

**推论：**

<div class="math-display">\[
dim \mathcal{PP}_m(\Delta)=(k+1)m, \quad dim \mathcal{S}_m(\Delta)=m+k
\]</div>

从定理可以看出，<span class="math-inline">\((x-x_i)_+^{m-j}(i=0,\cdots,k;j=1,\cdots,m_i)\)</span> 是空间 <span class="math-inline">\(\mathcal{S}\)</span> 的一组基。但是从计算的角度来看，这组基并不好，因为它没有局部性质：当 <span class="math-inline">\(x\)</span> 接近 <span class="math-inline">\(b\)</span> 时，为了计算 <span class="math-inline">\(s(x)\)</span>，需要计算所有基函数的值。我们需要更加局部化、对称化的基。

## 2. 差商

下面我们开始介绍 B 样条，在此之前先介绍差商：

**定义 2（差商）：**

给定节点

<div class="math-display">\[
t_1 \le t_2 \le \cdots \le t_{r+1} = \underbrace{\tau_1,\cdots,\tau_1}_{l_1} < \underbrace{\tau_2,\cdots,\tau_2}_{l_2} < \ldots < \underbrace{\tau_d,\cdots,\tau_d}_{l_d},\;\sum_{i=1}^d l_i = r+1
\]</div>

和函数 <span class="math-inline">\(f\)</span>，<span class="math-inline">\(f\)</span> 在点 <span class="math-inline">\(t_1, t_2, \cdots, t_{r+1}\)</span> 的 <span class="math-inline">\(r\)</span> 次**差商**为：

<div class="math-display">\[
[t_1,t_2]f\triangleq \begin{cases} \dfrac{f(t_2)-f(t_1)}{t_2-t_1} & t_1<t_2, \\ f^{'}(t_1) & t_1=t_2, \end{cases}
\]</div>

<div class="math-display">\[
[t_1,t_2,\cdots,t_{r+1}]f\triangleq \begin{cases} \dfrac{[t_2,t_3,\cdots,t_{r+1}]f-[t_1,t_2,\cdots,t_r]f}{t_{r+1}-t_1} & t_1<t_{r+1}, \\ \dfrac{1}{r!}f^{(r)}(t_1) & t_1=t_{r+1}, \end{cases}
\]</div>

## 3. B 样条

有了差商的定义，我们可以开始介绍 B 样条：

**定义 3（B 样条）：**

设 <span class="math-inline">\(\{y_i\}_{i=-\infty}^{+\infty}\)</span> 为一不减的实数列，对给定的整数 <span class="math-inline">\(i\)</span> 和 <span class="math-inline">\(m>0\)</span> 及所有实数 <span class="math-inline">\(x\)</span>，称

<div class="math-display">\[
Q_i^m(x)\triangleq \begin{cases} (-1)^m[y_i,y_{i+1},\cdots,y_{i+m}](x-\cdot)_+^{m-1} & y_i<y_{i+m}, \\ 0 & y_i=y_{i+m} \end{cases}
\]</div>

为 <span class="math-inline">\(m\)</span> 阶的、节点为 <span class="math-inline">\(y_i,y_{i+1},\cdots,y_{i+m}\)</span> 的**B 样条**。

若

<div class="math-display">\[
y_i \le y_{i+1} \le \cdots \le y_{i+m} = \underbrace{\tau_1,\cdots,\tau_1}_{m_1} < \underbrace{\tau_2,\cdots,\tau_2}_{m_2} < \ldots < \underbrace{\tau_d,\cdots,\tau_d}_{m_d},
\]</div>

则 <span class="math-inline">\(Q_i^m(x)\)</span> 显然是 <span class="math-inline">\(m\)</span> 阶的、节点为 <span class="math-inline">\(\tau_1,\tau_2,\cdots,\tau_d\)</span> 的、重度向量为 <span class="math-inline">\((m_1,m_2,\cdots,m_d)\)</span> 的样条函数。

由定义，可以很容易地计算出一些特殊的 B 样条：

1. **<span class="math-inline">\(m=1\)</span> 时：**

<div class="math-display">\[
Q_i^1(x)= \begin{cases} \dfrac{1}{y_{i+1}-y_i} & y_i \le x<y_{i+1}, \\ 0 & \text{else} \end{cases}
\]</div>

2. **<span class="math-inline">\(y_i<y_{i+1}=\cdots=y_{i+m}\)</span> 时：**

<div class="math-display">\[
Q_i^m(x)= \begin{cases} \dfrac{(x-y_i)^{m-1}}{(y_{i+m}-y_i)^m} & y_i \le x<y_{i+m}, \\ 0 & \text{else} \end{cases}
\]</div>

3. **<span class="math-inline">\(y_i=y_{i+1}=\cdots=y_{i+m-1}<y_{i+m}\)</span> 时：**

<div class="math-display">\[
Q_i^m(x)= \begin{cases} \dfrac{(y_{i+m}-x)^{m-1}}{(y_{i+m}-y_i)^m} & y_i \le x<y_{i+m}, \\ 0 & \text{else} \end{cases}
\]</div>

考虑 <span class="math-inline">\(m=1\)</span> 时，<span class="math-inline">\(Q_i^1(x)=\dfrac{1}{y_{i+1}-y_i}\;(y_i \le x<y_{i+1})\)</span>，对不同的 <span class="math-inline">\(y_i\)</span> 和 <span class="math-inline">\(y_{i+1}\)</span>，<span class="math-inline">\(Q_i^1(x)\)</span> 可能会非常大或非常小，这会给数值计算带来很大的误差。因此我们引入**规范 B 样条**：

**定义 4（规范 B 样条）：**

称

<div class="math-display">\[
N_i^m(x)\triangleq (y_{i+m}-y_i)Q_i^m(x)
\]</div>

为 <span class="math-inline">\(m\)</span> 阶的、节点为 <span class="math-inline">\(y_i,y_{i+1},\cdots,y_{i+m}\)</span> 的**规范 B 样条**。

显然 <span class="math-inline">\(m=1\)</span> 时，

<div class="math-display">\[
N_i^1(x)= \begin{cases} 1 & y_i \le x<y_{i+1}, \\ 0 & \text{else} \end{cases}
\]</div>

---

### 3.1 B 样条的性质

**定理 2（B 样条的性质）：**

1. **B 样条函数满足递推关系**：设 <span class="math-inline">\(m\ge2, y_i<y_{i+m}\)</span>，则对所有的 <span class="math-inline">\(x\in\mathbb{R}\)</span>，有

<div class="math-display">\[
Q_i^m(x)=\dfrac{(x-y_i)Q_i^{m-1}(x)+(y_{i+m}-x)Q_{i+1}^{m-1}(x)}{y_{i+m}-y_i}
\]</div>

2. 
   - 设 <span class="math-inline">\(y_l<y_{l+1}\)</span>，则在区间 <span class="math-inline">\(I_l\triangleq[y_l,y_{l+1}]\)</span> 上 <span class="math-inline">\(\mathcal{P}_m=span\{Q_i^m(x)\}_{i=l+1-m}^l\)</span>
   - 若 <span class="math-inline">\(l<r, y_{r-1}<y_r\)</span>，则 <span class="math-inline">\(\{Q_i^m(x)\}_{i=l+1-m}^{r-1}\)</span> 在 <span class="math-inline">\([y_l,y_r)\)</span> 上线性无关

3. **规范 B 样条形成单位分解**：即对任意 <span class="math-inline">\(x\in[y_j,y_{j+1})\)</span>，有 <span class="math-inline">\(\sum_{i=j+1-m}^{j}N_i^m(x)=1\)</span>

4. 设 <span class="math-inline">\(y_i<y_{i+m}, m>1, D_+\)</span> 为右导数算子，则

<div class="math-display">\[
D_+Q_i^m(x)=(m-1)\dfrac{Q_i^{m-1}(x)-Q_{i+1}^{m-1}(x)}{y_{i+m}-y_i}
\]</div>

5. 设 <span class="math-inline">\(y_i<y_{i+m}\)</span>，则

<div class="math-display">\[
Q_i^m(x)>0\;,\;y_i<x<y_{i+m}
\]</div>

<div class="math-display">\[
Q_i^m(x)=0\;,\;x<y_i\;\text{或}\;x>y_{i+m}
\]</div>

---

### 3.2 扩充分割

有了 B 样条，现在我们可以建立空间 <span class="math-inline">\(\mathcal{S}(\mathcal{P}_m,\mathfrak{M},\Delta)\)</span> 的一个有局部支集的基底。

我们知道 <span class="math-inline">\(dim(\mathcal{S})=m+\mathbf{K}\)</span>，其中 <span class="math-inline">\(\mathbf{K}\)</span> 为分割 <span class="math-inline">\(\Delta\)</span> 的节点数。然而在 <span class="math-inline">\(\mathbf{K}\)</span> 个节点上只能定义 <span class="math-inline">\(\mathbf{K}-m\)</span> 个 B 样条，因此我们还需要加入 <span class="math-inline">\(2m\)</span> 个点。于是，我们引入**扩充分割**：

**定义 5（扩充分割）：**

对给定的 <span class="math-inline">\(a<x_1<\cdots<x_k<b\)</span> 和 <span class="math-inline">\(1\le m_i\le m(i=1,\cdots,k)\)</span>，若 <span class="math-inline">\(y_1\le y_2\le\cdots\le y_{2m+\mathbf{K}}\)</span> 满足

<div class="math-display">\[
y_1\le y_2\le\cdots\le y_m\le a,\;\;b\le y_{m+\mathbf{K}+1}\le\cdots\le y_{2m+\mathbf{K}},
\]</div>

<div class="math-display">\[
y_{m+1}\le y_{m+2}\le\cdots\le y_{m+\mathbf{K}}=\underbrace{x_1,\cdots,x_1}_{m_1}<\cdots<\underbrace{x_k,\cdots,x_k}_{m_k},
\]</div>

则称 <span class="math-inline">\(\{y_i\}_{i=1}^{2m+\mathbf{K}}\)</span> 为空间 <span class="math-inline">\(\mathcal{S}(\mathcal{P}_m,\mathfrak{M},\Delta)\)</span> 的扩充分割。

一种特殊取法为

<div class="math-display">\[
y_1=y_2=\cdots=y_m=a,\quad y_{m+\mathbf{K}+1}=\cdots=y_{2m+\mathbf{K}}=b
\]</div>

这样我们在 <span class="math-inline">\(\{y_i\}_{i=1}^{2m+\mathbf{K}}\)</span> 上定义了 <span class="math-inline">\(m+\mathbf{K}\)</span> 个 B 样条 <span class="math-inline">\(\{B_i(x)\}_{i=1}^{m+\mathbf{K}}\)</span>，即 <span class="math-inline">\(N_i^m(x)\)</span>。

## 4. 样条函数的计算

现在我们已经有了多项式样条空间的一组有局部支集的基，可以开始考虑样条函数及其导数值的计算。

**定理 3（de Boor 算法）：**

设 <span class="math-inline">\(s(x)=\sum_{i}c_iN_i^m(x) \qquad (y_l\leq x<y_{l+1})\)</span>

则

<div class="math-display">\[
s(x) =\sum_{i=l+1-m}^{l}c_i^{[0]}N_i^m(x)=\cdots=c_i^{[m-1]}
\]</div>

其中

<div class="math-display">\[
c_i^{[0]}=c_i
\]</div>

<div class="math-display">\[
c_i^{[j+1]}=\alpha_jc_i^{[j]}+(1-\alpha_j)c_{i-1}^{[j]} \qquad (j=0,1,\cdots,m-2)
\]</div>

<div class="math-display">\[
\alpha_j=\dfrac{x-y_i}{y_{i+m-1-j}-y_i}
\]</div>

类似的，可以计算 <span class="math-inline">\(s(x)\)</span> 的导数值

<div class="math-display">\[
D_+^ds(x)=\sum_{i=l+d+1-m}^{l}c_i^{[d]}N_i^{m-d}(x)
\]</div>

其中

<div class="math-display">\[
c_i^{[0]}=c_i
\]</div>

<div class="math-display">\[
c_i^{[d]}=\dfrac{(m-d)(c_i^{[d-1]}-c_{i-1}^{[d-1]})}{y_{i+m-d}-y_i} \qquad (d=1,2,\cdots)
\]</div>

## 5. 多项式的开花（极形式）

接下来，我们引入多项式的开花（即极形式）：

**定义 6（多项式的开花/极形式）：**

设 <span class="math-inline">\(b(u)\)</span> 是一个 <span class="math-inline">\(n\)</span> 次多项式，将满足对角关系的、对称的、<span class="math-inline">\(n\)</span> 仿射的多项式 <span class="math-inline">\(b(u_1,u_2,\cdots,u_n)\)</span> 称为多项式 <span class="math-inline">\(b(u)\)</span> 的**开花**，或**极形式**。

- **对角关系**：<span class="math-inline">\(b(u)=b(u,\cdots,u)\)</span>
- **对称**：<span class="math-inline">\(b(u_1,u_2,\cdots,u_n)=b(u_{\sigma(1)},u_{\sigma(2)},\cdots,u_{\sigma(n)})\)</span>
- **<span class="math-inline">\(n\)</span> 仿射**：对每一个变量 <span class="math-inline">\(u_i\)</span> 都是仿射的

**定理 4：**

对于任意 <span class="math-inline">\(n\)</span> 次多项式 <span class="math-inline">\(b(u)\)</span>，存在唯一的开花，且

<div class="math-display">\[
b_i=b(\underbrace{0,\cdots,0}_{n-i},\underbrace{1,\cdots,1}_i) \qquad (i=0,1,\cdots,n)
\]</div>

是 <span class="math-inline">\(b(u)\)</span> 在 <span class="math-inline">\([0,1]\)</span> 上的 **Bézier 系数**，即

<div class="math-display">\[
b(u)=\sum_{i=0}^{n}b_iB_i^n(u)
\]</div>

其中 <span class="math-inline">\(B_i^n(u)\triangleq \binom{n}{i}u^i(1-u)^{n-i}\)</span> 为 Bernstein 多项式。

---

## 6. 广义 de Boor 算法

**定理 5（广义 de Boor 算法）：**

假设已知 <span class="math-inline">\(n+1\)</span> 个值 <span class="math-inline">\(b(t_{i+1},t_{i+2},\cdots,t_{i+n})\;\;(i=0,1,\cdots,n)\)</span>，我们可以通过如下算法计算 <span class="math-inline">\(b(u_1,u_2,\cdots,u_n)\)</span>：

<div class="math-display">\[
b_i^0=b(t_{i+1},t_{i+2},\cdots,t_{i+n})
\]</div>

<div class="math-display">\[
b_i^r(u_1,u_2,\cdots,u_r)=\frac{u_r-t_i}{t_{i+n+1-r}-t_i}b_i^{r-1}(u_1,u_2,\cdots,u_{r-1})+\frac{t_{i+n+1-r}-u_r}{t_{i+n+1-r}-t_i}b_{i-1}^{r-1}(u_1,u_2,\cdots,u_{r-1})
\]</div>

从而 <span class="math-inline">\(b_n^n(u_1,u_2,\cdots,u_n)=b(u_1,u_2,\cdots,u_n)\)</span>

## 总结

本文介绍了 CAGD 中的基础理论知识：

1. **多项式样条空间**：分片多项式构成的函数空间，具有一定的光滑性
2. **差商**：B 样条定义的基础
3. **B 样条**：具有局部支集的基函数，是 CAGD 的核心工具
4. **de Boor 算法**：高效计算样条函数值的算法
5. **极形式（开花）**：多项式的几何表示

这些知识为后续学习 NURBS、非均匀 B 样条等高级内容奠定了基础。
